A uniform distribution under the curve. Let f(x) = p̃(x) ≥ 0 be integrable, with 0 < Z = ∫ f(x) dx < ∞. The target is p(x) = f(x)/Z. Let 1{condition} be 1 when the condition holds and 0 otherwise. Introduce a height v and define the joint density

p^(x,v)=1Z1{0<v<f(x)}.

The full region beneath f has area Z. Integrating out v gives

∫p^(x,v)dv=∫0f(x)1Zdv=f(x)Z=p(x).

The two draws. Starting from xt, draw vt+1 uniformly between 0 and f(xt). For a height v, define Av = {x : f(x) ≥ v} and let |Av| denote its total length. The other conditional density is

p(x|v)=1{x∈Av}|Av|.

Draw xt+1 from this conditional. These are Gibbs updates for the joint density p̂, so they preserve p̂ and its x marginal p. The normalizing constant Z cancels from both conditionals. The chain’s samples remain dependent; a finite histogram need not exactly match p.

A disconnected slice. Suppose Av is a union of disjoint intervals Ij = [aj, bj], j = 1, …, K, with lengths ℓj = bj − aj. Choose an interval J with probability ℓJ / ∑j ℓj, then draw uniformly within IJ. Equal probabilities for intervals of different lengths would give the wrong conditional distribution. The green segments and probability table show this choice directly.

What this implementation illustrates. It finds every slice interval for the displayed one-dimensional targets, solves their endpoints numerically, and draws from their full union. Slice endpoints are independent of the plotting window. This is the full-slice conditional update described above. More general slice samplers can use other updates that preserve the uniform distribution on the slice; see Neal’s Slice Sampling paper.

Targets and scale. Write N(μ, τ²) for a Gaussian distribution with mean μ and variance τ². The Gaussian target uses f(x) = c exp(−(x − μ)²/(2τ²)). The mixture uses f(x) = c[w exp(−(x + m)²/(2τ²)) + (1 − w) exp(−(x − m)²/(2τ²))], where c > 0, 0 < w < 1, and m > 0. Its normalized target is w N(−m, τ²) + (1 − w)N(m, τ²). Multiplying f by c changes the scale of v, while leaving p and the x updates unchanged when the same uniform random draws are used.

Reading the plots. The main plot uses unnormalized f; the histogram uses normalized p. Enable the joint-sample overlay to see recent pairs (x, v) inside the shaded region. After discarding B complete iterations, the histogram uses xB+1, …, xt; x₀ and incomplete vertical draws are excluded. Bin heights are counts divided by the full retained sample count and bin width. The trace shows movement within and between modes.
